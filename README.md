# 🎮 Game Title (Working Name)

A fast-paced 3D action game built in **Unity**, focused on smooth movement mechanics like **sliding, sprinting, jumping**, and future systems like **grappling** and combat.

---

## 🚀 Features

• First-person / third-person movement controller
• Sprinting, jumping & air control
• Slide mechanic (with slope interaction)
• Combat animations (equip / attack)
• Pause menu & UI system
• Scene switching (Main Menu → Game Scene)

Planned:
• Grapple hook system
• Advanced enemy AI
• Movement states (walk / sprint / slide / air)
• Polished camera effects

---

## 🕹 Controls

| Action       | Key / Input    |
| ------------ | -------------- |
| Move         | WASD           |
| Jump         | Space          |
| Sprint       | Left Shift     |
| Slide        | Left Ctrl      |
| Attack       | Mouse Button 1 |
| Attack2       | Mouse Button 2 |
| Equip Weapon | Q              |
| Pause        | Esc            |

---

## 🧠 Systems Overview

**Movement System**
• Uses CharacterController
• Handles slopes, gravity, sliding, sprinting
• Includes state-based movement logic

**Combat System**
• Animator-driven attacks
• Equip / Unequip weapon
• Cooldown-based attack flow

**UI System**
• Main Menu
• Pause Menu
• Scene Switching with SceneManager
